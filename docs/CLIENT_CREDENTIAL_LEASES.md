# 客户端持钥与自动授权

> 新增可选「同步模式」：与下文代理模式不同，它由邮件 worker 使用独立持久密钥加密保存后端授权、邮件原件、正文及附件；正文和索引在数据库，原件与附件在 `mohua-mail-files` 独立卷，控制服务仅保存密文。取消绑定立即清除密码包及持续授权，30 天内仅可恢复归档。App 登录过期/设备撤销不会终止已开启的独立同步授权。停止同步需使用邮箱设置中的对应操作，不删除已保存副本。详情与密钥备份要求见 [同步模式](../SYNC_MODE_ZH.md)。


## 已实现的协议

新 iOS 邮箱在设备生成独立的 256 位邮箱密钥，以 AES-256-GCM 加密凭据。长期密文保存在 accounts.credential 的 client-v1 封装中；邮箱密钥保存在 WhenUnlockedThisDeviceOnly Keychain，不上传服务端。采用每邮箱独立恢复密钥，不采用所有邮箱共享的根密钥。

AES-GCM 互通格式：base64(nonce[12] || ciphertext || tag[16])；AAD 是 UTF-8 的 `mohua-credential-v1\n<account UUID>\n<revision UUID>`。每次密码更新使用新密钥及 revision。恢复密钥是 32 字节随机邮箱密钥的 base64，必须离线保管；更新密码后重新导出。新设备必须导入恢复密钥或重新输入邮箱密码。账号登录不自动提供解密密钥。

GET /api/accounts/:id/credential 需要有效 iOS 设备会话，返回长期密文、授权状态及五分钟一次性 challenge。客户端按本地规则解密长期密文，用新的随机临时密钥重新加密密码，经 HTTPS POST 到同一路径，带 challenge、revision、key、ciphertext、expiresAt。临时密钥不进入数据库。服务端原子检查账号、设备会话、密文版本和 challenge；已使用或服务器重启前的 challenge 无效。

期限为 1–365 天，0 表示无时间限制（协议 expiresAt:null）。客户端自动续期，无手动确认续期。规则留在客户端，不采纳服务端要求的更长期限。首次配置/恢复/修改规则及需要续期时生成新授权。服务器每分钟扫描，临近 24 小时或缺少授权时每邮箱最多每小时请求一次现有无正文同步推送。客户端每次刷新检查授权，前台、网络恢复和后台推送共用自动续期。iOS 唤醒及解锁后的密钥可用性不保证；失败时可等待下次打开 App。

服务端每秒清理到期授权，并在借用连接/登录时检查期限。清理关闭监听、空闲与在途读取连接及 SMTP 任务；发送中的不确定结果保留原有 unknown 语义，不自动重发。续期无须中断有效连接。Server 重启清空内存授权，包括无时间限制授权。

## 不兼容升级与撤销

旧格式邮箱配置不再受支持。POST/PATCH 必须提交客户端加密 envelope，提交 credential 明文直接拒绝；邮件服务没有 master.key 解密邮箱密码的回退路径。数据库仍有旧格式配置时拒绝启动。停服后执行 `docker compose run --rm --no-deps server node scripts/remove-legacy-mailboxes.mjs` 删除旧配置及关联 outbox，邮箱同步状态由外键级联删除，新格式配置保留。随后重新启动并用新版 iOS 添加邮箱。该操作不会删除邮箱服务商的邮件，也不会擦除历史备份。

设备撤销会清除由该设备授予的当前内存授权。关闭“允许本设备自动授权”会清除当前服务器授权，但其他设备仍有独立授权策略，可以重新授权。需要完全停止所有设备时删除邮箱配置或逐设备撤销。恢复密钥曾泄露时，需要更换邮箱密码及密钥，撤销设备本身不能让复制的恢复密钥失效。

## 安全边界与部署

长期密文与临时内存凭据分离可以降低磁盘/备份泄露的影响。运行中服务器仍能获得密码和邮件内容；完整进程/主机入侵可以读取临时密钥并截获密码。TTL 不是密码学撤销，泄露的服务商密码不会随授权到期失效。

正文/附件保持有界流式转发，Relay 不处理正文或邮箱密钥。Node/Swift 字符串及邮件库内部副本无法保证安全擦除；生产 IMAP/SMTP 处理已迁入独立受限 mail-worker 服务；没有引入硬件可信执行环境。详见 [邮件进程隔离](MAIL_PROCESS_ISOLATION.md)。不要宣称防 root 内存读取。

部署者应禁用 core/heap dump、限制调试和进程读取权限、禁用或保护 swap，确保代理不记录请求体，并采用 HTTPS。代码不能保证宿主机或云平台没有内存快照。部署状态以本次执行结果为准；此脚本必须在主 Server 停止后显式执行。

## 验证

新增测试覆盖密文认证、邮箱/设备/版本隔离、重放、过期、续期、设备撤销、重启丢失授权、不落盘和禁止降级。完整 Server 回归与 iOS 编译必须通过。真机锁屏唤醒/APNs 送达需要独立验收。
